# HackRise

HackRise is a full-stack coding practice platform built for students to solve coding problems, improve problem-solving skills, and track their learning progress.

## 🚀 Features

- User Registration
- User Login
- Admin Registration
- Admin Login
- JWT Authentication
- Cookie-Based Authentication
- Logout with Redis
- Input Validation

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- Redis
- JWT
- bcrypt
